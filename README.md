# 🍳 RecipeHub - Client Side

RecipeHub is a modern recipe-sharing web application built with **Next.js**. It provides an interactive platform where users can discover recipes, share their own cooking experiences, save favorite recipes, and access premium features.

The client-side application focuses on delivering a fast, responsive, and user-friendly interface with modern UI components, authentication integration, and seamless user experience.

---

## 🌐 Live Application

🔗 Live Website: `https://recipehub-self.vercel.app`

🔗 Backend Repository: `https://recipehub-server-dusky.vercel.app`

---

# 📌 Project Purpose

The goal of RecipeHub is to create a community-driven recipe platform where food enthusiasts can:

- Discover new recipes
- Share personal recipes
- Manage their cooking content
- Save favorite recipes
- Purchase premium membership
- Interact with a secure recipe ecosystem

The frontend provides a smooth user experience with dynamic pages, protected routes, responsive layouts, and role-based dashboards.
